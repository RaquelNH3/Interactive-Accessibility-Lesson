# Interactive-Accessibility-Lesson

Reflection Questions

What accessibility enhancements were the most challenging to implement, and why?

1. Changing the texts to avoid overlap, blending the background, and changing the elements to be AAA were the most difficult. The overlap could be handled various ways using blocks or adjusting size. Adjusting to AA-AAA took guess work and playing with elements until you got them right by adjusting color and size until it hit the desired value range. Also, my devtools pulled up, but it was not easy to find the contrast on the page. There were so many tools, and the player made it difficult to read individual page elements. The assignment also seemed to assume the viewer knows intermediate to advanced CSS.

2. How do ARIA attributes improve the experience for users relying on assistive technologies?

ARIA attributes allow assistive technologies like screen readers to be able to make the page usable for viewers that have different visual and auditory capabilities. It can help them identify elements like forms and buttons. It helps them skip over links. It increases the readability of the page. Overall, these attributes work togther so that everyone can use and experience the webpage/asset. 

3. What tools did you use to check color contrast, and how did they help?

I used built-in DevTools. They were not that easy to navigate. It was difficult to try and locate contrast in all the elements. Also, DevTools interacted awkwardly with Scrimba’s video player making it difficult to isolate what I was looking for to determine if it met WGAC guidelines or at least the AA standard.
